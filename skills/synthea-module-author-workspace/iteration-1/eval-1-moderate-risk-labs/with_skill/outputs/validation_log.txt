Notes
=====
- Chloride unit: LOINC display says "Moles/volume" but reported clinical unit is mEq/L.
  For monovalent ions, 1 mmol/L == 1 mEq/L, so mEq/L is the standard clinical reporting unit.
  The unit field in the Synthea module uses "mEq/L" per clinical convention and the HAPI DSE API spec.
- RDW-CV display "Erythrocyte [DistWidth]" is the canonical LOINC form; the familiar clinical label
  is "RDW-CV". The code is correct.
- Source of value ranges: references/hapi-labs.md (pre-validated project reference, 2026-07-22),
  which documents moderate-risk ranges derived from clinical literature for HF/frailty inpatients.
